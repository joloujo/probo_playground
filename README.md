## Repository Overview and Vision
This repository is meant to be a starting point for creativity and self-guided learning for the _Probabilistic Robotics_ course at Olin College of Engineering, providing an initial skeleton for a mobile robot simulation environment. The assignment associated with this branch provides extra support for implementing a linear Kalman Filter in the simulator.

## File Structure
```bash
├── src/
│   ├── simulator.py
│   ├── environment.py
│   ├── robot.py
│   ├── sensors.py
│   ├── viz.py
│   ├── utils.py
├── input/
├── output/
├── requirements.txt
├── README.md
├── simulator.md
├── kalman_filter.md
├── extended_kalman_filter.md
```

`src` houses the source code for this project.

`input` houses example input files; particularly a config file and a commands file. there are two example files present:
- `config_example.yaml`: used to configure the environment and sensor noise models
- `vel_cmd_example.csv`: a list of linear and angular velocity commands to execute

`output` houses output generated by the simulator. When run, the following files are created:
- `dataset_viz.png`: the simplest and clearest way to understand the simulator. A visualization of the environment overlaid with three robot trajectories: ground truth, odometry/dead reckoning, and GPS estimates.
- `env_info.pkl`: static environment data, including universal timestep size, bounds, obstacle dimensions, and landmark locations.
- `sensor_info.pkl`: static sensor data containing a list of sensors and the constants used to define the standard deviation of their respective Gaussian noise models.
- `groundtruth_log.pkl`: ground truth robot poses and states.
- `sensor_log.pkl`: the resultant noisy dataset from sensor samples.

## How to Use This Repository
This repository is a skeleton for you to use as a starting point for your own Kalman Filter! You should use the existing architecture and scaffolding as much as is useful for your learning, and you are welcome to structure the simulator however you see fit. The `src/` folder contains a basic outline of recommended files, classes, and functions, but these are by no means a requirement or a complete pipeline.

If you'd like to follow a more guided walkthrough of how to build your linear Kalman Filter, check out the `kalman_filter.md` file. For a walkthrough on building the Extended Kalman Filter, check out `extended_kalman_filter.md`.

## Merging This Repository With Your Repository

To get the new code on this branch into your local development repository, follow these steps:

1. If you haven't already, push your current code to your GitHub repository.

`git push origin main`

2. Next, set up the class's repository as a remote branch in your local repository.

`git remote add upstream git@github.com:probrobo26/probo_playground.git`

3. Finally, pull from the remote repository's `kalman_filtering` branch into the branch you're working on.

`git pull upstream kalman_filtering`
